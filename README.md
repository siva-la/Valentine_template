# Valentine_template

A one-page Valentine's Day website built with plain HTML, CSS and JavaScript. No frameworks, just open `index.html` in a browser.

# Features
- Floating hearts background
- Recap cards with hover effects
- 9 clickable hearts that reveal a secret message
- Memories timeline
- Responsive, mobile-friendly layout
